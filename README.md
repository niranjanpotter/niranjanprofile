# Niranjan Potter — Senior MuleSoft Developer & Technical Lead (Anime Portfolio)

An interactive, cinematic anime-movie style portfolio built for **Niranjan Potter**, Senior MuleSoft Developer and Technical Lead.

## Tech Stack
- Next.js 14
- React 18
- TypeScript
- Three.js / React Three Fiber
- Framer Motion
- Lenis Smooth Scroll

## Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) 🎬
